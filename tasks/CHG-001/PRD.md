# PRD · maskdesk — 本地文档脱敏客户端

- **version**: 2 · **date**: 2026-09-24 · **status**: APPROVED（approved_by: 主人，2026-09-24 经 gap 四问批准）
- **change**: CHG-001 · **上游策划**: casemask · **功能参考**: family_health 脱敏链路

## 1. 背景与立意

family_health 平台的「文档上传 → 手动脱敏 → 打包导出」是一条完整自洽的能力，但被耦合在中台系统里（需要启动前后端、多用户体系）。真实高频场景其实很轻：**医生/科研人员手里有几份病例，想在交给 AI 之前，在本机把它们安全脱敏**。casemask 策划案（本机已 clone）定义了这个独立产品：本地优先、零上传、格式归一化、圈选建规则、一键打包。

maskdesk = casemask 策划的落地实现，从 family_health 抽取已验证的行为逻辑（规则模型、线性脱敏、映射记录、ZIP 结构），以纯前端架构重写为 Windows 一键运行的轻量客户端。

**定位一句话**：AI 管线的隐私前置站——把任何文书安全地变成「可以交给 AI 的脱敏 Markdown」。

## 2. 目标用户与场景

- **谁**：医生、科研入组助理、健康管理师、需要交文书给 AI 的个人
- **核心场景**：拖入 3 份 DOCX 病例 → 逐份圈选姓名/住院号建规则（自动全文套用）→ 导出一个 ZIP（原文 + Markdown + 规则 JSON + 脱敏版）→ 把脱敏版喂给 LLM
- **使用环境**：Windows 10/11 单机，**全程离线可用**（隐私红线：文档不出机）

## 3. 功能需求

### FR-1 导入与格式归一化
- 拖拽/选择多文件批量导入：`.docx` `.pdf` `.md` `.txt`
- 自动在本地转换统一为 Markdown：DOCX 用 mammoth→HTML→turndown；PDF 用 pdfjs 抽取文本层（保留段落与标题层级）；MD/TXT 直接入列
- 队列视图：文件名、页数/字数、转换状态（成功/失败原因）、可预览
- **明示限制**：扫描图片型 PDF（无文本层）不支持，导入时明确提示（MVP 不做 OCR）

### FR-2 选中即脱敏（核心体验）
- 渲染后的 Markdown 上**划选文字** → 浮出建规则气泡：选标签（姓名/电话/日期/住院号/身份证/自定义）+ 自动生成占位符（如 `[姓名_1]`，可改）→ 确认
- 确认即生效：**全文所有相同内容立即替换为占位符并高亮**（含后续导入文档的自动套用）
- 规则类型：字面量（默认，re.escape 安全）与正则（高级，非法正则即时校验报错）——沿袭 family_health 双类型设计
- 原文/脱敏双视图切换 + 对照高亮；撤销上一条规则（还原该规则的全部替换）
- **强门禁沿袭**：导出时若文档 0 条替换但命中高风险 PII 特征（手机号/身份证正则族），弹提示确认「确认未脱敏导出」或返回建规则（family_health 的 `_HIGH_RISK_PATTERNS` 门禁逻辑，但导出权还给用户，不硬拦）

### FR-3 规则库管理
- 侧栏规则列表：标签、类型、pattern（脱敏展示）、占位符、命中次数、启停开关、删除
- 全项目规则跨文档复用；规则库可**导出/导入 JSON**（跨项目复用）
- 所有映射记录（原文 ↔ 占位符 ↔ 文档）在导出包中完整携带（可追溯，这是「一次性导出脱敏规则映射」需求的落点）

### FR-4 快速字段脱敏（通用脱敏）
- 独立「快速模式」页签：粘贴任意文本/字段 → 立即按当前规则库脱敏 → 输出区可复制/下载 `.md`
- 30+ 内置启发式识别器一键套用（手机号/身份证/日期/邮箱等正则族），可勾选启停——满足「只要有字段传输进来，就可以进行脱敏处理」

### FR-5 打包导出 ZIP
- 一键导出 `.zip`，结构：

```
maskdesk-export-<项目名>-<日期>.zip
├── manifest.json            # 项目元数据：文件清单、规则统计、时间、版本
├── rules.json               # 脱敏规则库 + 全部映射记录（原文↔占位符↔文档）
├── raw/                     # 未脱敏原始文件（原样字节）
├── markdown/                # 转换后的原始 Markdown
└── sanitized/               # 脱敏后 Markdown（占位符版）
```

- 浏览器下载流（Electron 下落盘到用户选择目录）；manifest 含每个文件的规则命中统计

### FR-6 Windows 桌面化
- electron-builder 打包：安装包（NSIS）+ 便携版（解压双击即用）双形态
- 双击运行 → 主界面直接可用，无需任何配置/网络/账号
- 应用名/图标/产品信息按 maskdesk 品牌

## 4. 美学与体验方向（按美学种子库决策）

> 依据：agent-taste-seed-system 情绪定位 → **「清晰理性」为主，底色是「庄重典雅」的信任感**。

- **主基因：瑞士平面/包豪斯**（code-genes/01）——医疗数据工具的本命：白/浅灰底、三级文字灰、唯一功能色、12 列栅格、锐利 2px 圆角、零渐变零投影（flat）；专业与可信来自「对齐」本身
- **功能色**：医疗青 `#0f766e`（承 family_health 视觉血脉），只用于强调/命中高亮/CTA，面积 ≤10%
- **辅基因（点睛）：脱敏遮蔽条隐喻**——选中建规则的瞬间，命中处渲染为「黑色遮挡条滑入」的动效（脱敏的物理视觉语言），这是全产品的记忆点；除此之外装饰为零
- **排版**：行高 1.6+、栅格严格对齐、留白 32px 起步；危险操作（删除规则）用约束性确认而非红色恐吓
- 完整参数（色板/CSS 变量/反模式）在 SPEC 阶段按 code-genes/01 卡逐项落实施工

## 5. 非目标（明确不做）

- OCR / 扫描件识别；云同步/账号体系；多人协作
- HIPAA/《个保法》合规承诺（沿 casemask 免责声明：科研与个人工作流辅助）
- 除 Windows 外的其他平台打包（macOS/Linux 后续按需）
